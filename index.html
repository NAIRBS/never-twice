    Shared hue. Background, text and accent each call random(--hue-key, …). A named key with no scope keyword shares one value across the page, so the colours always match.

    Per-element by default. Each letter of the title and each event card gets its own rotation, because plain random() is scoped per element, property and position.

    Readable on purpose. Only hue, size, spacing and angles are random. Lightness is fixed for each theme, so contrast holds on every roll.

    Where CSS stops. random() only returns numbers. Picking which pasta and replies to show, a layout or a font family are discrete choices, so a few lines of JS do those parts.
